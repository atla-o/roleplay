Roleplay for Linux

Godot 4.7.2. The measured terrain is inside the tarball. Nothing is downloaded on first run.

  • roleplay-linux-x86_64.tar.gz for typical PCs
  • roleplay-linux-aarch64.tar.gz for Asahi Linux on Apple Silicon and other arm64 machines

Unpack, then ./run.sh. If Vulkan Forward+ leaves a black window, run ./run-compat.sh. That uses OpenGL 3 Compatibility. Output is written to roleplay.log beside the binary.

Robot: W throttle, S reverse, A and D steer. Q raises the blade, E lowers it, Z and C tilt it. Settings, bottom left, switches body and teleports. ./run.sh --bench prints a frame rate and quits.
